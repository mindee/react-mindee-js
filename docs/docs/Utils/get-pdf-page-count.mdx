# getPDFPageCount

- Type PDFSource : `(source: string | Blob | ArrayBuffer | Uint8Array) => Promise<number>`

> Returns the number of pages without rendering anything.

```javascript
getPDFPageCount(file: PDFSource).then((pageCount) => {
  // Do something with the page count
})
```

:::tip
If you also need to render pages, call [openPDF](/docs/Utils/open-pdf) once and read `numPages` from the handle so the document is only parsed once.
:::
