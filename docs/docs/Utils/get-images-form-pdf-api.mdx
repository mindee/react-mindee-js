# getImagesFromPDF

:::caution Deprecated
`getImagesFromPDF` renders and holds **every** page in memory at once. Use [openPDF](/docs/Utils/open-pdf) or the [usePDFDocument](/docs/Utils/use-pdf-document) hook to render pages progressively instead.
:::

- Type : `(source: PDFSource, maxPages?: number, onSuccess?: () => void, resolution?: number) => Promise<string[]>`

> Renders every page of a PDF to a PNG data URL. Pages that fail to render are skipped, so the result may be shorter than the page count. `source` accepts a URL string, a `File`/`Blob`, an `ArrayBuffer` or a `Uint8Array`.

```javascript
getImagesFromPDF(file).then((images) => {
  // images: ['data:image/png;base64,...', ...]
})
```

- **`maxPages`** : rejects with a `TooManyPagesError` when the document has more pages.
- **`onSuccess`** : called once the document has been accepted, before pages are rendered.
- **`resolution`** : target pixel count of each page, see [PDFPageOptions](/docs/Utils/open-pdf#page-options).
